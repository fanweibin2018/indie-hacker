# 设计简报 · 独立开发者内容门户（粘贴进 Claude Design 使用）

> 用法：打开 claude.ai/design，新建项目，把下面「给 Claude Design 的提示」整段粘贴进对话框作为起点，然后用对话和内联批注迭代。完成后按「交付清单」导出，交回工程仓库实现。

---

## 给 Claude Design 的提示（直接复制以下整段）

我要为一个面向独立开发者（indie hacker）的双语内容知识门户设计界面。请帮我建立设计系统并产出关键页面。

**产品**：围绕产品生命周期五个阶段组织内容的知识库——需求挖掘（discover）、设计（design）、开发（build）、营销（market）、商业分析（business）。内容分两类并交叉关联：原创文章/指南、结构化资源/工具目录。

**受众**：中英双语的独立开发者。语气硬核、专业、可信。

**视觉方向**：编辑式 / 杂志感（Editorial）+ 克制的工程气质。拒绝模板感、拒绝通用 SaaS 落地页套路。要有清晰的标度对比、间距节奏、深度层叠、有性格的排版、语义化色彩、设计过的 hover/focus/active 态。

**设计系统要求**：
- 排版：标题用有性格的字体（候选 Space Grotesk / Sora），正文用高可读无衬线（Inter）；中文用思源黑体/系统字体栈兜底。双字体配对。
- 字号走流式（clamp），间距有节奏而非处处均匀。
- 色彩：浅色为主，**不默认暗色**；为五个阶段各定一个语义标识色（discover/design/build/market/business），用于色码导航、阶段标签、卡片强调，而非纯装饰。同时给出一套深色模式，两种都要有意图。
- 全部颜色/字号/间距/圆角/阴影/动效缓动以设计 token（CSS 自定义属性）形式给出。
- 动效只用 transform / opacity，尊重 prefers-reduced-motion。

**需要设计的页面/组件**：
1. **首页（Landing）**：用 bento / 编辑式分栏打破均匀网格。包含价值主张、五阶段入口（用各自语义色）、精选文章与精选资源、邮件订阅区。
2. **阶段页（如 discover）**：上半为该阶段精选文章流，下半为可筛选的资源卡片网格（筛选维度：分类 / 定价 free·freemium·paid / 标签）。需要展示筛选控件的设计。
3. **文章详情页**：编辑式正文排版（标题/引文/代码块/图片）、"本文用到的工具"关联资源区、评论区占位、上/下篇导航。
4. **核心组件**：导航栏（含语言切换 中/EN、搜索入口、深浅色切换）、文章卡片、资源卡片、阶段标签 chip、筛选控件、页脚、邮件订阅表单。

请先产出设计系统（色板含五阶段色、字体、token），再产出上述三个页面的桌面与移动版式（断点参考 320 / 768 / 1024 / 1440）。

---

## 交付清单（设计定稿后交回工程仓库）

按优先级，能给越靠前的越好：

1. **最佳**：导出代码（HTML/CSS 或 React 组件）+ 设计 token（CSS 自定义属性 / JSON）。
2. **次选**：设计系统规格——完整色值（含五阶段色的明确 hex/oklch）、字体名与字重、字号阶梯、间距阶梯、圆角/阴影值、动效缓动曲线。
3. **至少**：三个页面（桌面+移动）的高清截图 + 上述色值/字体清单。

交回方式：把导出的代码/token 文件放进本仓库（建议 `design/` 目录），或把截图与规格贴给工程侧（Claude Code），由其在 Astro 中实现还原。

---

## 注意

- 最终视觉以你在 Claude Design 的定稿为准，但需符合上面的编辑式方向与设计系统要求。
- 五阶段语义色一旦定稿，会成为整站色码系统的基础，请确保五色彼此区分度足够且与正文对比度达标（无障碍）。
- 工程侧（Astro）会严格还原你的定稿；token 化程度越高，还原越精确。
