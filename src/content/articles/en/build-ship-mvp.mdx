An MVP's goal isn't "perfect" — it's "get real feedback as fast as possible." You'll learn more on launch day than from a month of guessing.

## Minimal pre-launch checklist

1. **Core flow works**: The happy path runs end-to-end without crashing.
2. **Errors are handled**: Network failures and form validation must show a message — no blank screens.
3. **Domain and HTTPS ready**: Vercel provides free HTTPS on every deploy.
4. **Basic analytics in place**: At minimum, know whether anyone visited and where they dropped off.

## Recommended stack

- Frontend: Astro / Next.js
- Deployment: Vercel (push to deploy)
- Code hosting: GitHub (free private repos)

> Don't wait until it's "a bit more polished" — ship, then iterate.
